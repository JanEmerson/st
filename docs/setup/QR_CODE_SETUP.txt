ST Asset Management System - QR Scanner Setup

HTTP/LAN scanner configuration

Current recommended LAN URL:
http://172.18.20.100/st

QR SCANNING MODES

1. Scan with Phone Camera (recommended for HTTP/LAN)
   - Open ST on the phone.
   - Open QR Scanner.
   - Tap "Scan with Phone Camera".
   - The phone operating system opens its camera/photo capture interface.
   - Photograph the printed ST QR label.
   - ST decodes the captured image using jsQR and opens the asset_scan.php URL.
   - This method does not require webpage getUserMedia permission and is suitable for an HTTP LAN site.

2. Start Live Camera
   - This mode uses the webpage camera API (getUserMedia) and jsQR.
   - Browsers require a secure context for webpage camera access, normally HTTPS.
   - On http://172.18.20.100/st, the button will intentionally report that live camera is unavailable and direct the user to "Scan with Phone Camera".

QR DECODER

The scanner page loads jsQR 1.4.0 from jsDelivr:
https://cdn.jsdelivr.net/npm/jsqr@1.4.0/dist/jsQR.js

The decoder runs in the browser. The captured image is processed client-side by the scanner page.

If the phone has no internet access, the decoder script cannot be downloaded and image scanning will not work. In that case, either restore internet access on the phone or install a locally bundled copy of jsQR in frontend/js and change the scanner page to load it locally.

QR URL FORMAT

QR codes generated by the application point to:
http://172.18.20.100/st/asset_scan.php?token=<secure-token>

The scanner only accepts URLs ending in /asset_scan.php with a non-empty token.

After changing the application base URL, regenerate/reprint QR labels if the QR code contains the old full URL.
