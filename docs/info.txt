25. Legacy / Existing Assets

Old assets are stored in the same assets table as other assets. Use Assets → Add Asset + Asset Source = Legacy / Existing when entering an existing/old asset manually.

Record when available:
- Asset Source = Legacy / Existing
- Current Condition = New, Good, Fair, Poor, or Damaged
- Legacy / Previous Reference = old property, SAP, or other reference number
- Date Added to ST = date the record was entered into this system

A legacy reference is optional because some old records may not have an available SAP/property reference.

Use the Asset Source filter on the Assets page to locate legacy records. Legacy assets continue to use the normal assignment, transfer, turnover, history, and clearance workflow. Disposal is intentionally not included in this phase.
